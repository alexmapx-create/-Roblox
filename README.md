# DRAGON KINGDOM TYCOON — development build

This branch delivers the Roblox Studio place and the full source/assets archive.

- `downloads/DragonKingdomTycoon.rbxl`: open on Windows/macOS with Roblox Studio.
- `downloads/DragonKingdomTycoon.zip`: complete project, original development artwork, docs, tests, and place files.
- `downloads/SHA256SUMS.txt`: SHA256 checksums of the two files.

On GitHub, open a file and choose **Download raw file**. The ZIP includes `docs/STUDIO_SETUP.md`. Before testing an unpublished place, explicitly enable the documented Studio-only memory mode (temporary and unsaved), or publish an owner-controlled test place and enable API access for real DataStore tests.

Cloud checks passed 58 domain/security/persistence assertions. UI/world stand-ins are mocks. Real Studio rendering, multiplayer, live DataStore, devices, and FPS are unrun. Original PNG/audio files need owner upload and binding; procedural dragon geometry remains development art pending final custom meshes and rigged clips.
